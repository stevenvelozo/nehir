Nehir.
A scrolling tiling window manager for macOS.
Download latest Source on GitHub

# About

Nehir manages your windows as scrolling columns rather than a fixed grid — windows live on an endless horizontal strip you scroll and jump through, so you always have room for one more without rearranging everything. It builds a fork-safe “shell” layer on top of a niri-style engine, centered on the Control Deck: one keyboard chord (⌘D) that drives everything.

# Getting started

1. Download the latest .pkg above and open it (or unzip the .zip and drag Nehir.app into Applications).

2. Launch Nehir, then grant it Accessibility access when prompted (System Settings → Privacy & Security → Accessibility). Window management needs it.

3. Press ⌘D to open the Control Deck. That's the hub for everything below.

Requires macOS 15+. Signed with a Developer ID and notarized by Apple.

# The Control Deck (⌘D)

  • 1…0 jump to a column (numbers overlay each window)
  • ⌘+digit send the current window to that position
  • Focus / Move step focus or shuffle windows around
  • Width & grid width presets and a keyboard/mouse resize grid
  • Configure pin a per-window minimum width or float rule
  • Layout switch families — River, Blades, or Free (all-floating)
  • Display toggle menu-bar / Dock auto-hide, scroll bars, and more, live
