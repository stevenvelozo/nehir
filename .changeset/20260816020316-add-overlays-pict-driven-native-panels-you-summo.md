Add Overlays: pict-driven native panels you summon with a hotkey. Author them as small JavaScript files in ~/.config/nehir/overlays/ — a draggable grid of files (e.g. recent Desktop screenshots you drag straight into any window, with selection, Quick Look, and arrow-key navigation) or an interactive web view. Overlays support an optional title bar, resizing, remembered size/position, and developer-defined key actions.
