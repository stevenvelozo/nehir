Add a second OSD summon shortcut that reaches across Screen Sharing. A configurable chord (default ⌘J) opens the OSD on whichever Mac you're actually typing into: when a Screen Sharing window is focused it passes through to the remote Mac's OSD, otherwise it opens the local one. ⌘D stays local as before. Both summon chords are now editable in Settings.
