New windows can open at a remembered width. Set a window's column width with ⌘D→W and Nehir remembers it for that app — or for a single window by its title — so the next window of that app opens at the same width instead of the ~50% default (great for browsers or Screen Sharing sessions you always want wide). View, set, or clear it in the ⌘D→G Configure screen's new Open width row.
